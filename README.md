# astro090-pm.github.io

Сайт-портфолио Романа Понурова: https://astro090-pm.github.io

- Тексты кейсов — `content/cases/*.md` (те же, что в [product-cases](https://github.com/astro090-pm/product-cases)).
- Главная страница и список кейсов — в `build.py`.
- Пересобрать после изменений: `pip install markdown && python build.py`, затем закоммитить HTML.

Сайт статический, без фреймворков: GitHub Pages отдаёт файлы из ветки `main`.

## Как опубликовать пост

1. Создайте файл `content/posts/ГГГГ-ММ-ДД-короткое-имя.md`:

   ```
   ---
   title: Заголовок поста
   date: 2026-10-20
   tags: продукт, AI
   ---

   Первый абзац — он же анонс на главной.

   Дальше текст в Markdown.
   ```

2. `python build.py`, затем закоммитьте изменения. Пост появится на главной (10 на страницу) и в разделе «Посты».

## Книги

Список — в `content/books.txt`, одна книга на строку: `Тема | Название | Автор | Чем полезна | slug поста-рецензии`.
Рецензия — обычный пост с тегом `книги`. Пока список пуст, страница «Книги» и пункт меню не показываются.

Пост о книге: в шапке `cover: assets/books/<файл>.jpg` (обложка в ленте и в посте) и `rating: 9` (оценка из 10), тег `книги`.

## Поиск и тёмная тема

`assets/site.js`: поиск по `search.json` (собирается в `build.py` из всех страниц; открывается кнопкой с лупой, «/» или Ctrl+K) и переключатель темы (по умолчанию — как в системе, выбор запоминается в браузере).

## Английская версия

`python build.py` собирает и `/en/`: переведённые посты и кейсы — в `i18n_en/content/` (те же имена файлов), подписи интерфейса — в `i18n_en/ui.json`, английские данные — в `en_data.py`, страницы с длинным текстом — в `en_pages.py`. Сборка печатает предупреждение, если на английских страницах осталась кириллица.

## Направления личного бренда

Тексты страниц «Мой путь в ИИ» (`agents.html`), «Мой путь в коучинге» (`coaching.html`), «Студентам» (`students.html`) и кейса `projects/weekend-planner.html` — в `brand.py`, на двух языках.

Правила: только подтверждённые факты; статусы — `done`/`practice` (есть опыт или практика), `proto` (прототип), `part` (частично), `wip` (в процессе), `plan` (планируется).

- **Запись дневника практики в ИИ** — пост с тегом `ИИ-агенты` (в английской версии — `AI agents`); разделы: дата, цель, что сделано, технические решения, что заработало, как проверял, проблемы, выводы, следующий шаг, ссылки.
- **Запись рефлексии по коучингу** — пост с тегом `коучинг` (`coaching`); без имён и деталей сессий. Когда этап маршрута пройден, поменяйте его статус в `brand.py` (`COACH` → `route`) и добавьте дату и подтверждение.
- **Материал для студентов** — пост по шаблону из 10 пунктов (см. страницу «Студентам»); ссылку на него добавьте в `STU` → `route` или `cats` в `brand.py`.
- **Статус в дорожной карте ИИ** — `AI` → `map` в `brand.py`, вместе с подтверждением (ссылкой на код, тесты или кейс).

## Служебные файлы

`sitemap.xml`, `robots.txt` и `404.html` пересоздаются при каждой сборке.

## Проверка перед публикацией

```bash
python build.py
python -m http.server 8000      # открыть http://localhost:8000
```
