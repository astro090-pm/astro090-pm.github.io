AI agents

Here I document my path into AI agents, from theory to practice. Each stage covers what it is, where I tried it hands-on and what I learned. My main testing ground is Weekend Planner, an open-source agentic Telegram bot.

Roadmap

  1. 01

    How LLMs work theory

    Tokens, context, temperature, why a model “hallucinates” and how to write prompts that work reliably.

  2. 02

    Structured output and tools practised

    The model answers not with text but with JSON following a schema, and decides itself which tool to call: weather, events, search.

    • Practice: response schemas and the tool-calling loop in Weekend Planner
  3. 03

    The agent loop practised

    The agent plans its steps, calls tools, checks the result and decides what to do next. Where you need an agent and where a plain script is enough.

    • Practice: scout, planner and critic
  4. 04

    MCP — the tool protocol practised

    A standard way to connect external tools and data to a model, so you don't rewrite the integration for every agent.

    • Practice: my own MCP server with four tools
    • Practice: bolz.dev — an MCP connector for real agent actions
    • Post: bolz.dev — an MCP connector that lets AI agents take real-world actions
  5. 05

    Multi-agent systems and A2A practised

    Several agents with different roles negotiate with each other over the Agent-to-Agent protocol.

    • Practice: Weekend Planner agents talk over A2A
  6. 06

    Browser agents practised

    The agent opens pages, reads them and acts on a website where there is no API.

    • Practice: the scout's browser tool
  7. 07

    Orchestration and recovery practised

    What to do when a tool fails, the model returns garbage or loops: retries, fallback models, checks, step limits.

    • Practice: retries and fallback providers
  8. 08

    Evals practised

    How to measure agent quality: a set of cases, automated checks, comparing versions before and after a change.

    • Practice: 32 eval cases
  9. 09

    Agent product metrics practised

    Agent-native metrics: share of tasks solved without a human, cost and response time, retention and user ratings.

    • Practice: funnel, retention and ratings in the bot
  10. 10

    Memory and RAG ahead

    How an agent remembers the user and relies on its own documents, not just the model's knowledge.

  11. 11

    Observability and safety ahead

    Traces, logs and the cost of every step; protection against prompt injection and dangerous actions.

  12. 12

    Agent in production ahead

    Launching to real users: A/B tests, quality monitoring, agent economics.
