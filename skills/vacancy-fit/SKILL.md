# Разбор вакансии под мой опыт

## Шаг 1. Разбери вакансию

Из текста вакансии (или страницы по ссылке) выпиши:
- роль и уровень;
- задачи («что будешь делать»);
- обязательные требования и «будет плюсом»;
- ключевые слова, которые повторяются (например: B2C, агенты, MCP, эвалы, A/B, метрики).

## Шаг 2. Собери опыт кандидата

Прочитай резюме, кейсы, проекты и посты пользователя. Для каждого опыта — роль, период, результат в цифрах.

## Шаг 3. Карта соответствия

Таблица:

| Требование вакансии | Чем подтверждаю | Сила (сильно / частично / нет) |
|---|---|---|

В колонке «Чем подтверждаю» — конкретный кейс, проект или цифра, со ссылкой, если она есть на сайте или GitHub.

## Шаг 4. Пробелы и как их закрыть

Для каждого «частично / нет»:
- можно ли закрыть уже имеющимся опытом, переформулировав его;
- что сделать до интервью (пет-проект, пост, курс, демо) — реалистично по сроку;
- как честно ответить, если спросят.

## Шаг 5. Что подсветить

- 3 пункта для первого экрана резюме / сайта под эту вакансию;
- 3–5 строк сопроводительного письма: почему эта роль, чем полезен, один кейс с цифрой;
- 5–7 вероятных вопросов на интервью и опорные ответы (STAR: ситуация → задача → действия → результат).

## Правила

- Только факты из материалов пользователя; не приписывать опыт, которого нет.
- Если вакансия про конкретные технологии (MCP, A2A, браузерные агенты, эвалы) — искать подтверждения в коде и проектах, а не только в резюме.
- Итог — короткий: таблица, пробелы, три пункта, вопросы. Без воды.
