# Пост для сайта из заметки

Превращает сырой материал в пост формата `content/posts/ГГГГ-ММ-ДД-slug.md` для статического сайта-блога.

## Шаг 1. Определи тип поста

| Тип | Признак | Теги по умолчанию |
|---|---|---|
| Событие | лекция, выступление, запуск, акселератор | по теме + `продакт` |
| Научная статья | журнал, ВАК, DOI | `научная статья`, тема |
| Конференция | доклад, сборник | `конференция`, тема |
| Книга | прочитанная книга | `книги`, тема; `cover`, `rating` |
| Проект / кейс | продукт, MVP, питч | `продакт`, сфера, модель |

## Шаг 2. Дата

- Дата — когда событие произошло, а не когда пишется пост.
- Если точной даты нет — бери из источника (дата сборника, выпуска журнала, слайда) и скажи пользователю, что дата условная.
- Не добавляй строк вида «пост опубликован позже».

## Шаг 3. Шапка

```
---
title: <конкретный заголовок, что произошло и почему интересно>
date: ГГГГ-ММ-ДД
thumb: assets/posts/<slug>.png      # картинка справа в ленте
tags: <тег1>, <тег2>, <тег3>
cover: assets/books/<файл>.jpg       # только для книг
rating: 10                           # только для книг, если пользователь назвал оценку
stage: 4                             # только для постов про ИИ-агентов, номер этапа
---
```

Slug — латиница через дефис, 2–4 слова по смыслу.

## Шаг 4. Текст

- Первый абзац — 1–2 предложения: что произошло. Он же уйдёт в анонс ленты, поэтому без ссылок.
- Дальше 2–4 раздела `##`: «О чём», «Главные выводы / тезисы», «Зачем это продакту».
- Списки — где перечисление; цифры — с источником.
- В конце — ссылки на связанные страницы сайта (кейс, исследования, проекты) относительными путями `../cases/<slug>.html`.

## Шаг 5. Картинка

- Если есть фото или слайд — обрежь до квадрата 480×480 и сохрани в `assets/posts/`.
- Если нет — сделай плашку: цветной фон из палитры сайта, крупное слово (тип или название) и подпись мелко.

## Правила

- Без выдуманных фактов, цитат и оценок. Чего нет в материале — спроси.
- Внутренние данные работодателя, имена респондентов и коллег — не публиковать; обобщать.
- После поста пересобрать сайт (`python3 build.py`) и проверить, что пост появился в ленте и на странице тега.
